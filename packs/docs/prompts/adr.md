Write an ADR for: $@

Follow the adr skill format. Read the relevant code first so the context and
alternatives are grounded in what actually exists. Number it after the last
ADR in docs/adr/ (create the dir if needed), status "proposed". List at least
two real alternatives with the one-line reason each was rejected, and state
the consequences honestly - including what becomes harder.
